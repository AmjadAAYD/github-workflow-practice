# GitHub workflow practice

A public sandbox for practicing GitHub branches, pull requests, co-author attribution, and Q&A Discussions.

## Account ownership

AmjadAAYD and Amjad-AAYD are two accounts owned by Amjad. Exercises here test GitHub workflows and achievement eligibility; they do not represent independent collaborators or independent support requests.

## Exercises

- Keep a focused change on a topic branch.
- Use GitHub no-reply addresses for account attribution.
- Inspect the commit authors and pull-request diff before merging.
- Use Q&A Discussions to document the workflow and test accepted-answer behavior.
- Report a badge only after it actually appears on the profile.

No credentials or private project data belong in this repository.

# Co-author attribution checklist

1. Start a topic branch from main.
2. Make one focused change and inspect git diff.
3. Set the author address to the account responsible for the commit.
4. Put each Co-authored-by trailer after a blank line in the commit message.
5. Use the no-reply email supplied in each GitHub account's email settings.
6. Open a pull request and confirm GitHub resolves both account identities.
7. Merge with a merge commit to preserve the original commit and its trailers.
8. Check the profile separately: recognized authorship does not prove achievement eligibility.

For this exercise, both listed accounts belong to the same person.

Reference: https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors
